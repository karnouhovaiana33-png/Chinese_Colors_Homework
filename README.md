# Цветовая миссия · ДЗ урока 2

Самостоятельная страница ДЗ на 25 минут, максимум 30 минут активной работы.
В пакете только ДЗ, его изображения, озвучка и файлы письма. Переходов на карту и уроки нет.

Загрузите содержимое этой папки в отдельный репозиторий GitHub. В Settings → Pages
выберите Source: GitHub Actions. Workflow публикует страницу index.html.

Локальный запуск: открыть index.html. Для микрофона нужен доступ браузера;
можно пройти задания без записи голоса. Прогресс остаётся в браузере ученика.
Записи голоса не отправляются и удаляются при смене экрана.

Иллюстрация дракона и текстура бумаги сгенерированы ImageGen для этого ДЗ.
Лицензии библиотеки письма и данных находятся в vendor/.
